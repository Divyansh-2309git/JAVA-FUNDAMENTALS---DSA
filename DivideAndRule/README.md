# Divide & Conquer Overview

## What this topic teaches
Divide and Conquer breaks a complex problem into smaller sub-problems, solves them recursively, and combines their solutions. This module demonstrates classic Merge Sort.

## Concepts Covered
- Divide step: Splitting array into left and right halves
- Conquer step: Recursively sorting sub-arrays
- Combine step: Merging two sorted sub-arrays in linear time O(N)

## Programs Included

| Program | Description |
| :--- | :--- |
| [MergeSort.java](MergeSort.java) | Implements Merge Sort algorithm with guaranteed O(N log N) time complexity. |

## Key Java Concepts
- **Stable Sort**: Merge Sort preserves the relative order of equal elements.
- **Auxiliary Space**: Requires O(N) temporary array space during merge step.

# Binary Trees Overview

## What this topic teaches
A Binary Tree is a hierarchical data structure where each node has at most two children (left and right). This module covers tree construction from preorder traversals, BFS level-order traversal, and tree metric calculations.

## Concepts Covered
- Tree Node representation (, , )
- Recursive tree construction from preorder sequence
- Level Order Traversal (BFS) using Queue with null level markers
- Tree Height, Node Count, and Sum of Nodes calculation

## Programs Included

| Program | Description |
| :--- | :--- |

| [TreeHeightAndMetrics.java](TreeHeightAndMetrics.java) | Calculates Tree Height, Total Node Count, and Node Sum recursively. |

# Greedy Algorithms Overview

## What this topic teaches
Greedy algorithms build up a solution piece by piece, always choosing the next piece that offers the most immediate benefit (locally optimal choice) to find a global optimum.

## Concepts Covered
- Greedy Choice Property & Optimal Substructure
- Interval Scheduling & Activity Selection
- Sorting elements based on end time/profit ratios

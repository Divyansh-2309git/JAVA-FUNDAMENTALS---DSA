# Backtracking Overview

## What this topic teaches
Backtracking is an algorithmic technique for solving problems incrementally by exploring decision trees and abandoning (backtracking) paths that fail to meet constraints.

## Concepts Covered
- Decision Tree Exploration
- State mutation during forward recursion and state restoration during unwinding
- Subset generation (2^N possibilities)

## Programs Included

| Program | Description |
| :--- | :--- |
| [BacktrackOnArrays.java](BacktrackOnArrays.java) | Demonstrates array mutation during forward recursion and restoration on backtracking. |
| [FindSubsets.java](FindSubsets.java) | Generates all 2^N subsets of a given string using recursive decision tree. |

## Key Java Concepts
- **State Restructuring**: Ensuring temporary modifications to arrays/lists are reversed after recursive calls return.

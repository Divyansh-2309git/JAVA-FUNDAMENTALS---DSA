# Linked List Overview

## What this topic teaches
A Linked List is a linear data structure where elements (nodes) are stored in memory dynamically and connected via pointers. This module covers Singly Linked List operations, pointer manipulation, searching, list reversal, middle finding, cycle detection, and cycle removal.

## Concepts Covered
- Node structure (,  reference)
- Head and Tail pointer management
- Insertion (front, end, middle) O(1) & O(N)
- Deletion (first, last, index)
- Reversal of Linked List (Iterative)
- Floyd's Cycle Detection Algorithm (Slow & Fast pointers)
- Cycle Removal and Palindrome Check
